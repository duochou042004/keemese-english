## Tutor-password reset CLI

Scratchpad script against the running `keemese-e2e` stack (generated throwaway credentials; the new password was never printed):

```text
before: login 204 | me 200
docker compose -f deploy/compose.yaml -p keemese-e2e --profile app exec -T app dotnet Keemese.Api.dll --reset-tutor-password
cli exit 0, stdout: New temporary tutor password (shown once; change it at the next login): <redacted, 12 chars>
old session me: 401
old password login: 401
temporary password login: 204 | me 200 role tutor mustChangePassword true
psql: audit_events → auth.tutor_password_reset | user
```

A second run (needed to restore the tutor for the en capture below) completed the operator path: the CLI's temporary password signed in, and `POST /api/auth/change-password` back to the E2E password returned 204.

FR-AUTH-AC9 holds: a one-time 12-character password, the flag is set, existing sessions end, the old password stops working, and the action is audited. Noise: the CLI also writes `Cannot load library libgssapi_krb5.so.2` to stderr. This is Npgsql probing for optional GSS/Kerberos support in the chiseled image; the command still exits 0. It is cosmetic, so it was left as is.

## Security review

`security-reviewer` read the whole M1 diff and returned **PASS** with low/info items only. It checked threats T1–T6, T8, T9 and T14–T19. M1 has no `/api/me/**` routes; `/api/students` sits behind the Tutor policy and its DTOs are tutor-only. Only `lang` is kept in browser storage, `dangerouslySetInnerHTML` is lint-banned, `safeRedirect` rejects `//`, backslashes and other origins, and logout clears the query cache. CI keeps `contents: read`, and gitleaks is pinned by SHA.

- **Low, fixed in this branch:** a placeholder `Security:IpHashSalt` was accepted, which would make the audit IP hashes reversible ([fixes](#fixes-in-this-branch)).
- **Info, not fixed:** a user changing their own password writes no audit row. T14 doesn't require one, and adding it would be a feature, so it's left for a later packet if wanted.
- **Info, accepted as designed:** Playwright traces of failed E2E runs are uploaded as artifacts of a public repository. They hold only per-run throwaway credentials and invented fixtures.
